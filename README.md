# ErrandGo

Get Things Done. Anywhere.

ErrandGo is a mobile-first global errand marketplace foundation where users can post tasks, discover errands, apply to help, communicate, and manage their wallet.

## Stack
- React
- Vite
- Lucide React
- Responsive CSS

## Brand
- Electric Purple: #6C3BFF
- Vibrant Orange: #FF8A00
- Fresh Green: #20C997
- Soft White: #F8F9FC
- Deep Navy: #172033

## Run locally
```bash
npm install
npm run dev
```

## Current foundation
- Responsive dashboard
- Mobile bottom navigation
- Errand discovery/search
- Category browsing
- Post-errand modal
- Global currency selector foundation
- Wallet/navigation foundation
- Premium ErrandGo visual system

Production authentication, database, payments, maps, realtime chat, identity verification and notifications require backend/provider credentials and should be connected through secure server-side integrations before launch.
